# Search and Filtering

## Objective

The Hospital Appointment Management System provides search and filtering features to help hospital staff quickly locate appointments, patients, and doctors.

---

## Search Features

The system allows users to search using:

- Patient Name
- UHID (Unique Hospital ID)
- Doctor Name
- Appointment Number

---

## Filter Options

Appointments can be filtered by:

- Department
- Doctor
- Appointment Date
- Appointment Status
- Appointment Type
- Priority

---

## Benefits

- Faster appointment lookup
- Better appointment management
- Improved hospital workflow
- Reduced manual effort
